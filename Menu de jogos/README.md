# 🎮 Menu de Jogos em Java

Este projeto é uma aplicação de console interativa desenvolvida em Java que centraliza quatro jogos clássicos em um único menu. O projeto demonstra a aplicação de Programação Orientada a Objetos (POO), organização de pacotes e lógica de controle de fluxo.

## 🕹️ Jogos Incluídos

O sistema permite escolher e jogar as seguintes opções diretamente pelo terminal:

1.  **Sudoku**: Desafio de lógica e preenchimento de números.
2.  **Forca**: Jogo clássico de adivinhação de palavras.
3.  **Campo Minado**: Jogo de estratégia e dedução.
4.  **Batalha Naval**: Jogo de estratégia de guerra naval.

## 🛠️ Tecnologias e Conceitos

* **Linguagem:** Java.
* **Arquitetura:** Organização em pacotes (`sudoku`, `forca`, `campominado`, `batalhanaval`).
* **Conceitos de Java:** Uso da classe `Scanner` para entrada de dados, laços de repetição (`while`), estruturas condicionais (`if/else`) e chamadas de métodos de diferentes instâncias.
* **Contexto:** Desenvolvido como parte do aprendizado em **Análise e Desenvolvimento de Sistemas (FATEC)**.

## 🚀 Como Executar

Para rodar o menu de jogos, siga os passos abaixo:

1.  **Certifique-se de ter o JDK instalado.**
2.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/ViniciusSalviano/Fatec-Atividades-Projetos.git](https://github.com/ViniciusSalviano/Fatec-Atividades-Projetos.git)
    ```
3.  **Navegue até a pasta do projeto:**
    ```bash
    cd "Menu de jogos"
    ```
4.  **Compile o código principal:**
    ```bash
    javac Main.java
    ```
5.  **Execute o programa:**
    ```bash
    java Main
    ```

## 📂 Estrutura de Código

O código principal (`Main.java`) utiliza um loop que mantém o programa ativo até que o usuário escolha a opção de sair (opção 5), garantindo uma experiência contínua de uso.
