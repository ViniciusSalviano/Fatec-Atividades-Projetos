# 📚 Fatec - Atividades e Projetos

Repositório com atividades, exercícios e projetos desenvolvidos durante o curso de **Análise e Desenvolvimento de Sistemas** na FATEC.

Aqui estão reunidos exercícios práticos, desafios e projetos acadêmicos utilizados para estudo e evolução nas disciplinas do curso.

---

## 🚀 Objetivo

Este repositório foi criado para:

- Praticar lógica de programação
- Desenvolver habilidades com diferentes linguagens e tecnologias
- Registrar minha evolução durante a faculdade
- Organizar atividades e projetos acadêmicos

---

## 📂 Sobre o Repositório

O conteúdo está organizado em diferentes pastas contendo:

- Exercícios práticos
- Atividades de disciplinas
- Projetos acadêmicos
- Estudos e testes de código

Como o repositório reúne diversos exercícios e materiais de estudo, alguns projetos possuem estruturas e objetivos diferentes entre si.

---

## 🎯 Aprendizados

Durante o desenvolvimento das atividades, foram praticados conceitos como:

- Programação Orientada a Objetos
- Estruturas de repetição e decisão
- Vetores e matrizes
- Métodos e funções
- Manipulação de dados
- Organização de código
- Versionamento com Git

---

## 📌 Observações

Este repositório possui fins educacionais e representa minha trajetória de aprendizado durante a graduação.
